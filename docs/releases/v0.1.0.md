# Proxy Stability Doctor v0.1.0

Initial public release.

## Highlights

- Adapter-first Bash CLI for local HTTP/SOCKS proxy diagnostics.
- Diagnostic-first safety model with dry-run repair by default.
- Generic `custom` adapter and diagnostic `falemon` adapter.
- Configurable ports, probe targets, state directory, and trusted restart command.
- Post-restart verification before repair is considered successful.
- Bounded compact logs and redacted proxy output.
- Mock-adapter tests and GitHub Actions CI.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/HanchengQiao/proxy-stability-doctor/main/scripts/install.sh | PROXY_DOCTOR_VERSION=v0.1.0 bash
```

or clone the repository and run:

```bash
./tests/run_tests.sh
./bin/proxy-doctor version
```
